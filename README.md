# Dashboard de Cancelamentos e Impacto Financeiro — Power BI

## Objetivo

Desenvolver um dashboard para identificar padrões de cancelamento e avaliar seus impactos financeiros, permitindo uma análise mais clara sobre comportamento de pedidos e possíveis pontos de melhoria.

## Etapas realizadas

* Importação e organização dos dados
* Tratamento e limpeza dos dados
* Padronização de informações
* Relacionamento entre tabelas
* Criação de KPIs e medidas
* Desenvolvimento do dashboard interativo

## KPIs desenvolvidos

📉 Total de cancelamentos
📊 Taxa de cancelamento
💰 Impacto financeiro dos cancelamentos

## Análises realizadas

* Cancelamentos por categoria
* Cancelamentos por cliente
* Evolução dos cancelamentos ao longo do tempo
* Identificação de padrões de comportamento

## Ferramentas utilizadas

* Power BI
* Power Query
* DAX

## Principais insights

* A maior concentração de cancelamentos ocorreu em categorias específicas.
* Os cancelamentos não ficaram concentrados em poucos clientes, indicando um comportamento distribuído.
* O impacto financeiro dos cancelamentos apresentou relevância para acompanhamento estratégico.

## Resultado

Criação de um dashboard interativo para auxiliar no acompanhamento de cancelamentos e apoiar decisões baseadas em dados.
